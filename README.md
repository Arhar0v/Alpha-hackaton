# ИИ-помощник для предпринимателей в Telegram
## Назначение решения:
Решение помогает предпринимателям не теряться в информационном шуме. Бот анализирует потребности пользователя и точечно рекомендует качественные курсы, статьи и материалы для развития бизнеса. Подходит как для новичков (база и основы), так и для опытных владельцев бизнеса (прокачка конкретных навыков), экономя их время на поиск нужной информации.
## Архитектура решения
1. **Клиент (Telegram-бот):** Точка входа для пользователя. Принимает текстовые запросы (вопросы, поиск материалов) и возвращает готовый ответ.
2. **Векторизация и поиск (Embeddings):** 
   * База знаний (описания курсов, лекций и вебинаров) предварительно векторизуется с помощью модели `sergeyzh/LaBSE-ru-turbo` (sentence embedding).
   * Запрос пользователя также переводится в векторное представление.
   * Поиск релевантных материалов осуществляется на основе **косинусного сходства** между вектором запроса и векторами описаний обучающих материалов.
3. **Генерация ответа (LLM):** 
   * Найденные релевантные документы (контекст) вместе с описанием/профилем пользователя передаются в LLM от **Groq**.
   * Модель анализирует контекст и генерирует персонализированный, связный ответ с рекомендациями.
4. **Выдача результата:** Сформированный текст возвращается в Telegram-бот и отправляется пользователю.
