# ИИ-помощник для предпринимателей в Telegram

## Назначение решения
Решение помогает предпринимателям не теряться в информационном шуме. Бот анализирует потребности пользователя и точечно рекомендует качественные курсы, статьи и материалы для развития бизнеса. Подходит как для новичков (база и основы), так и для опытных владельцев бизнеса (прокачка конкретных навыков), экономя их время на поиск нужной информации. Также бот умеет вести список задач и напоминаний.

## Архитектура решения
1. Клиент (Telegram-бот): Точка входа для пользователя. Принимает текстовые запросы (вопросы, поиск материалов) и возвращает готовый ответ.
2. Векторизация и поиск: 
   * База знаний (описания курсов, лекций и вебинаров) предварительно векторизуется с помощью модели `intfloat/multilingual-e5-small` (sentence embedding), создается индекс HNSW в векторном хранилище Chroma.
   * Запрос пользователя также переводится в векторное представление, далее выполняется поиск по индексу.
3. Генерация ответа (LLM): 
   * Найденные релевантные документы (контекст) вместе с описанием/профилем пользователя передаются в LLM от Groq, при этом учитывается история (последние 5 сообщений, это изменяемый параметр).
   * Модель анализирует контекст, вопрос, историю, профиль и генерирует персонализированный, связный ответ с рекомендациями.
4. Выдача результата: Сформированный текст возвращается в Telegram-бот и отправляется пользователю.
5. Дополнительный функционал: Есть возможность устанавливать напоминания, а также получать информацию об обучающих материалах, которые подбираются на основе запросов пользователя (строим эмбеддинги на основе истории запросов и сравниваем с эмбеддингами обучающих материалов — описание, название, по косинусному сходству подбираем релевантные материалы).

##Api_Groq можно получить по ссылке: https://console.groq.com/
##Токен для бота получается у @BotFather в Telegram

## Одна команда для запуска через Docker
Для сборки и запуска проекта достаточно выполнить следующую команду в корневой директории:
docker compose up --build
